Observability & Monitoring

Infrastructure Monitoring with Zabbix & Grafana

24/7 Visibilidade & Telemetria em Tempo Real
Problema

Ausência de visibilidade unificada da saúde dos servidores, ativos de rede e links de comunicação, resultando em detecção tardia de falhas e tempo elevado para resolução de incidentes (MTTR).

Objetivo

Centralizar a coleta de métricas de hardware, sistema operacional e tráfego de rede com emissão de alertas proativos antes do impacto aos usuários.

Solução & Arquitetura

Deploy de servidor Zabbix em ambiente Linux com Zabbix Agents nos hosts críticos e consultas SNMP v2/v3 nos switches, access points e firewall FortiGate. Integração com Grafana para criação de dashboards visuais executivos e operacionais.

Tecnologias Utilizadas

Zabbix Grafana SNMP Linux FortiGate
Resultado Mensurável

Monitoramento contínuo de 100% dos ativos críticos com dashboards em tempo real e gatilhos de alerta, prevenindo indisponibilidades de infraestrutura.

Automation & Deployment

Automated OS Deployment with FOG Project

~1h → ~5min Redução no Tempo de Preparação
Problema

Processo de formatação, instalação de sistema operacional e configuração de softwares em novas máquinas executado manualmente via mídia física, consumindo em média 1 hora por equipamento.

Objetivo

Automatizar a distribuição e restauração de imagens padronizadas pela rede corporativa, escalando o provisionamento e reduzindo o tempo operacional.

Solução & Arquitetura

Implementação de servidor FOG Project em ambiente Linux virtualizado (Hyper-V / Windows Server), com suporte a boot PXE na rede local. Captura de imagens golden master customizadas com drivers e softwares pré-instalados para deploy multicast e unicast.

Tecnologias Utilizadas

FOG Project Windows Server Hyper-V PXE Boot Networking Automation
Resultado Mensurável

Tempo de provisionamento reduzido de ~1 hora para aproximadamente ~5 minutos por máquina, garantindo 100% de conformidade de imagem.

Network & Security

Network & Security Infrastructure with FortiGate

Zero-Trust Segmentação de Redes & VPN Segura
Problema

Ambiente de rede plano sem segmentação lógica entre servidores, estações de trabalho e visitantes, além da necessidade de acesso remoto seguro e criptografado para colaboradores.

Objetivo

Estruturar uma topologia segura com segregação de tráfego por VLANs, túneis VPN corporativos e inspeção de políticas de firewall centralizadas no FortiGate.

Solução & Arquitetura

Criação de VLANs dedicadas (Gerência, Servidores, Usuários, Visitantes), configuração de rotas estáticas, regras de firewall granulares, VPNs SSL com autenticação e integração SNMP para auditoria de tráfego.

Tecnologias Utilizadas

FortiGate VLAN Segregation SSL / IPsec VPN Firewall Policies SNMP Telemetry
Resultado Mensurável

Isolamento total entre zonas de rede críticas e acesso remoto estável e criptografado com conformidade de segurança.

CI/CD & Delivery

Automated CI/CD Pipeline Workflow

GitOps Automação de Build & Validação
Conceito

Estruturação de esteira contínua para validação estática de código (linting), checagem de integridade estrutural e entrega contínua sem risco de erros manuais em produção.

Fluxo da Esteira

A cada commit ou Pull Request na branch principal, o GitHub Actions executa jobs sequenciais de validação, testes estáticos e publicação automatizada.

Implementação

Workflow em YAML integrado ao repositório, com execução de linters e publicação imediata para o ambiente de borda (CDN Netlify).

Tecnologias Utilizadas

GitHub Actions Docker Netlify CDN
Benefício Operacional

Eliminação de deploys manuais com feedback instantâneo de integridade a cada alteração de código.
